# SIRIUS Python Client Notebooks

This repository contains Jupyter notebooks demonstrating the programmatic use of the [SIRIUS](https://bio.informatik.uni-jena.de/software/sirius/) platform, to annotate and analyze LC-MS/MS metabolomics data.

## Notebook Projects

- **[FoldChange](FoldChange/README.md)**: Replicates the protocol for untargeted LC-MS/MS metabolomics annotation and differential abundance (fold change) analysis from the STAR Protocols publication using a public rosemary dataset.
